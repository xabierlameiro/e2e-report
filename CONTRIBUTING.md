# Contributing

This repository contains auto-generated Playwright E2E test reports. It is updated automatically by CI workflows from the source repository.

## How this works

1. CI workflow in [the-last-dance](https://github.com/xabierlameiro/the-last-dance) runs Playwright E2E tests
2. The HTML report is committed to this repository
3. GitHub Pages serves the latest report at the published URL

If you find a bug, please open an issue in the [source repository](https://github.com/xabierlameiro/the-last-dance).
